# anti-slop

Скилл для кодовых агентов: убирает ИИ-слоп из текста и кода.

Слоп — это текст или код, который выглядит сделанным, но не несёт информации. Проверка одна: убери фразу — смысл не изменился? Тогда это слоп.

Работает в OpenCode, Claude Code, Codex, Cursor и любом агенте, который читает `SKILL.md` или `AGENTS.md`.

## Что ловит

| Область | Примеры |
|---|---|
| Лексика EN | delve, tapestry, vibrant, crucial, intricate, leverage, utilize, seamless, robust (вне инженерии), harness, showcase, unlock, elevate |
| Лексика RU | является, данный, осуществлять, ключевой момент, неотъемлемый, в современном мире, стоит отметить, таким образом, широкий спектр |
| Структура | три пункта ради ритма, «не просто X, а Y», вступление-разогрев, вывод-пересказ, хедж-стопка, одинаковые по длине предложения |
| Формат | длинное тире в каждой фразе, жирный для важности, эмодзи в деловом тексте |
| Факты | выдуманные числа, цитаты, бенчмарки, отзывы, логотипы клиентов, «99.9% uptime» |
| Код | комментарий-пересказ строки ниже, обёртка на один вызов, мёртвые обработчики, `// TODO` в шипнутом коде, `Something went wrong` |
| UI | кнопки без назначения, выдуманная статистика, hero + сетка карточек, три тарифа по умолчанию, CTA «Начать» |
| README и коммиты | бейджи без CI, Features с эмодзи, `update files`, `fix bug` |

Скилл не режет валидацию на границах доверия, обработку ошибок, защиту данных и доступность (контраст 4.5:1, focus-visible, клавиатура, зоны 44px). Это содержание, а не слоп.

## Установка

### OpenCode

```bash
git clone https://github.com/0x00ef-team/anti-slop ~/.config/opencode/skills/anti-slop
```

Скилл подхватывается при старте. Проверка: спроси агента «какие скиллы доступны», в списке будет `anti-slop`.

### Claude Code

```bash
git clone https://github.com/0x00ef-team/anti-slop ~/.claude/skills/anti-slop
```

Или в проект: `.claude/skills/anti-slop/`.

### Codex

Codex читает `AGENTS.md`. Скопируй блок правил из `agents-snippet.md` в `~/.codex/AGENTS.md` или в `AGENTS.md` проекта.

### Любой другой агент

Положи `SKILL.md` туда, где агент ищет инструкции, либо вставь его содержимое в системный промпт.

## Использование

Агент применяет правила сам, когда пишет текст, README, доки, коммит или ответ. Триггеры: `anti-slop`, `антислоп`, «звучит как ИИ», «как ChatGPT», «перепиши по-человечески», `make it sound human`.

Проверка руками, по списку из раздела 7 в `SKILL.md`: вырежи каждое прилагательное без потери факта, найди три предложения одной длины, проверь числа на источник, проверь первый и последний абзац.

## Структура

```
anti-slop/
├── SKILL.md           # правила для агента
├── agents-snippet.md  # сжатая версия для AGENTS.md
├── README.md
└── LICENSE
```

## Как править под себя

Список слов в `SKILL.md`, раздел 1. Добавляй свои маркеры, которые бесят в твоей нише.

Для правки чужого текста скилл требует минимальный diff: замена слова вместо переписывания абзаца, сохранение фактов и структуры.
